# Linux System Monitoring Lab 

## Goal
The goal here is to build a Bash script that collects basic Linux system information and saves it to a text report.

## What It Monitors
- Current date and time
- Current user
- Memory usage 
- Disk usage 
- Running processes sorted by CPU usage

## Tools Used 
- ubuntu Linux 
- Bash scripting
- Linux command-Line tools

## How to Run 
1. Open the project folder. 
2. Run `./monitor.sh`. 
3. Open the generated report to review the system information. 

## Security Log Monitoring 
- The script searches linux authentication logs for failed passweord attempts and saves matching entries in the generated report
